# ระบบ Affiliate สำหรับ WooCommerce

ระบบพันธมิตรสำหรับ WooCommerce รองรับการสร้างลิงค์พันธมิตร เงื่อนไขการให้ยอด Commission หลากหลาย การติดตามยอดขาย สร้างรายงาน ยืนยันตัวตน และการจ่ายค่าตอบแทนให้กับพันธมิตร

**หมายเหตุ** ระบบ Affiliate นี้จะใช้ตาราง wp_users เดิมที่อยู่ในระบบ โดยจะมีการเพิ่มคอลัมน์ refCode เข้าไปในตาราง wp_users เดิมของ Wordpress เพื่อรองรับระบบ Affiliate

## คุณสมบัติ
* แบ่งอัตรา Commission ตามหมวดหมู่สินค้า
* "ระบบยิ่งขายยิ่งได้" เพิ่มอัตราคอมมิชชั่นเมื่อถึงยอดที่กำหนด
* ผู้ใช้ Affiliate ต้องยืนยันตัวตนก่อนจะสามารถเริ่มขาย (การรักษาภาพลักษณ์ของแบรนด์)
* ลิงค์ Affiliate ติดตามผล 30 วัน ตามมาตรฐานของระบบ Affiliate สากล
* รองรับการแจ้งเตือนบน LINE และ Email

## การติดตั้ง

สามารถติดตั้งปลั้กอินนี้ได้โดยการดาวน์โหลดไฟล์นี้จาก Github หน้านี้ และอัพโหลดลงในหน้า /wp-admin/plugin-install.php หลังจากอัพโหลด และเปิดใช้งาน (Activate) ระบบจะทำการสร้างตารางและคอลัมน์ใหม่โดยอัตโนมัติ

## การใช้งานฝั่ง Affiliate

เข้าไปที่ URL เว็บไซต์ของคุณตามด้วย **/affiliate/dashboard/** เพื่อเข้าสู่ระบบ Affiliate สำหรับผู้ใช้งานฝั่ง Affiliate ซึ่งหลังจากสมัครสมาชิกและส่งหลักฐานแล้ว ผู้ใช้งานจะสามารถ

* แสดงรายการประวัติคำสั่งซื้อที่มาจากการแนะนำของเขาได้ 
* สามารถแก้ไขข้อมูลธนาคารได้
* ดูตารางอัตราคอมมิชชั่น (Commission Table) สำหรับสินค้าหมวดหมู่ต่าง ๆ ในร้าน
* ดูรายละเอียดการสั่งซื้อของคำสั่งซื้อที่มาจากการแนะนำของเขาได้
* ส่งคำขอการถอนเงินได้

## การใช้งานฝั่ง Back Office Admin

เข้าไปที่ URL เว็บไซต์ของคุณตามด้วย **/wp-admin/admin.php?page=affiliate** คุณจะพบเมนูต่าง ๆ ที่ใช้จัดการเงื่อนไขต่าง ๆ ในระบบ รวมถึงเนื้อหา และออกรายงาน

## ระบบสามารถกำหนดเงื่อนไข Commission ได้ดังนี้
1. กำหนด % Commission ตามประเภทสินค้า
2. ระดับ % Commission ตามยอดขาย (Tiered Commission) โดยแบ่งเป็นสามขั้น
